# Pizza Sales Analysis: SQL Querying & Excel Dashboard

## ⨠ Project Overview
This end-to-end data project explores transactional pizza sales data to unlock actionable business insights regarding revenue, ordering patterns, and product performance. The project showcases a full data workflow: executing backend relational data analysis using **SQL Server** and building a frontend, executive-ready interactive dashboard using **Microsoft Excel**.

## ⨠  Project Objectives
* **Financial Metrics:** Calculate total revenue, average order value, and total volume sold.
* **Trend Analysis:** Identify peak operational hours and busiest days of the week.
* **Product Performance:** Isolate the top 5 best-selling and bottom 5 worst-selling pizzas.
* **Tool Mastery:** Practice writing clean SQL aggregate queries and constructing dynamic Excel chart elements.

---

## 🛠️ Tools Used
* **SQL Server:** For querying, filtering, and structuring raw relational database tables.
* **Microsoft Excel:** For data modeling, pivot tables, and UI dashboard design.

---

## ⨠  Technical Skills Demonstrated

### 1. SQL Analysis Concepts
* **Aggregations:** Leveraging `SUM`, `COUNT`, and `ROUND` to establish primary KPIs.
* **Date Manipulation:** Extracting breakdown metrics by days and months (e.g., `DATENAME`, `DATEPART`).
* **Data Ordering & Logic:** Deploying `GROUP BY`, `ORDER BY`, and conditional filtering to isolate key trends.

### 2. Excel Dashboard Features
* **Dynamic KPI Cards:** Built custom formula blocks tracking overall operational totals.
* **Advanced Charting:** Designed dual-axis time-series lines and custom progress-bar charts.
* **Interactive Slicers:** Implemented a unified monthly Timeline filter for dynamic stakeholder reporting.

## ⨠  Key Insights Discovered
* **Peak Times:** Friday and Saturday evenings see the highest transaction volumes, with a daily maximum rush occurring between 12:00 PM – 1:00 PM and 5:00 PM – 8:00 PM.
* **Customer Preferences:** **Classic Category** pizzas and **Large Size** options represent the largest market shares in revenue contribution.
* **Product Standouts:** The **Classic Deluxe Pizza** represents the highest demand overall, while the **Spinach Supreme Pizza** sits at the lowest performance tier.
